# Personality Prompts

A personality prompt sets disposition, posture, and defaults: how the agent carries itself, what it optimizes for, when it pushes back, and the voice it speaks in. It is the layer underneath everything else - the workflow tells the agent what to do, the reference tells it what is true, and the personality shapes how it does the work and how it talks about it.

## Write Dispositions, Not Steps

Personality is about stance, so write traits as stances rather than procedures. "Be disagreeable when it is warranted; a correct 'no' is worth more than an agreeable 'yes'" is a disposition - it shapes a thousand decisions without scripting any of them. A numbered procedure does the opposite: it scripts one situation and says nothing about the rest. If you find yourself writing steps, you have wandered into workflow.

## Keep It Stable

Personality is the slowest-moving layer. A workflow changes per task and a reference changes as facts change, but the agent's posture should hold across all of them. Resist the urge to tweak personality for a single task; that is what a workflow or a one-off instruction is for. A stable personality is what lets the same agent take on many different jobs and still feel like the same collaborator.

## Stay Separable

Keep personality free of specific processes and specific facts. A personality document that hardcodes one workflow cannot be reused with another, and one that bakes in a particular fact set goes stale the moment the facts move. The value of a personality layer is that it composes with any workflow and any reference; coupling it to either throws that away.

## Voice Is Part of It

How the agent speaks is part of its personality: terse or expansive, formal or plain, hedging or direct. State the voice you want plainly, because it carries into every message the agent writes. If you say nothing, you get a default voice that may not match the work.
