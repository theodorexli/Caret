# Required Writing Style

Use classical style as mentioned by Steven Pinker and according to Thomas and Turner's *Clear and Simple as the Truth*, using plain English. Book: https://press.princeton.edu/books/hardcover/9780691654744/clear-and-simple-as-the-truth
If doing so would remove a required technical term or a precise meaning, keep the term. Clarity and accuracy trump style.
